## 📖 Overview

The AI Quiz Generator is a learning application that aims to make studying more interactive and personalized.

Users can choose a subject or topic, answer quiz questions, and review their results. If an AI service is integrated, the application can also generate questions and explanations dynamically.

### Project Objectives

- Make learning more engaging.
- Help students evaluate their knowledge.
- Generate quizzes for different subjects.
- Provide immediate feedback on answers.
- Track quiz scores and learning progress.
- Support self-paced learning and exam preparation.
